## Context
ADR-0005 sets MineCore's CRS policy (PROJ, no ballpark transformations, local
mine grids). The first users work in Turkey, so CRS defaults, the CRS picker
and transformation warnings must match Turkish practice and official sources.

## Questions
1. Which projected CRSs are in use for mining and exploration (ED50 UTM 6°,
   ED50 3° TM, ITRF96/TUREF 3° TM, WGS 84 UTM), with EPSG codes and areas of use.
2. What MAPEG requires for licence (ruhsat) coordinates, and what the e-Maden
   system uses; which regulation says so.
3. Official ED50 ↔ ITRF96 transformation (TKGM/HGK, BÖHHBÜY): method,
   parameters or grids, published accuracy; whether EPSG/PROJ contain them, with
   EPSG transformation codes and accuracy.
4. Heights: TUDKA-99, geoid models (TG-03, THG-09, TG-20): availability,
   licence, whether PROJ-data ships them.
5. Local mine grid practice in Turkish operations, if publicly documented.
6. A recommended CRS list for MineCore's picker (Turkey), with EPSG codes.

## Rules
Every factual claim has a source URL and a short quote. Mark each claim
VERIFIED (primary source seen) or UNCERTAIN. Prefer primary sources (Resmî
Gazete, TKGM, HGK, MAPEG, EPSG registry, PROJ docs).
