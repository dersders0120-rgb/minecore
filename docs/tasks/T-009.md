## Context
The M2 desurvey kernel (Rust) will be validated against reference values that
its author did not produce. ChatGPT computes them independently, two ways.

## Conventions (binding, from docs/ARCHITECTURE.md)
X east, Y north, Z up, metres. Azimuth in degrees clockwise from north [0, 360).
Dip in degrees, negative below horizontal (-90 = vertically down). Depth is
measured along the hole from the collar. Between stations the trace is a
circular arc (minimum curvature). Above the first station the first direction
applies; beyond the last station the trace continues straight.

## Required cases
1. Vertical hole; 2. constant inclined hole (az 45, dip -60); 3. pure build
(az 90, dip -90 to -60 over 100 m); 4. pure turn at dip -45 (az 0 to 90 over
150 m); 5. build + turn, 4 stations, irregular spacing; 6. azimuth wrap
350 to 10; 7. identical consecutive stations (zero dogleg); 8. points between
stations, exactly at stations, and beyond the last station.

## Method
Compute each point (a) with the closed-form arc formula and (b) by fine
numerical integration of the slerp-interpolated tangent. Both must agree within
1e-9 m. Include the Python code used.

## Report back
`tests/reference/desurvey/cases.csv` with columns
`case_id,collar_x,collar_y,collar_z,station_depths,station_azimuths,station_dips,depth,x,y,z`
(stations as `|`-separated lists, values to 1e-6 m) and
`tests/reference/desurvey/README.md` with the derivation, dogleg angles, ratio
factors and the code.
