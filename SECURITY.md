# Security policy

## Supported versions

Only the latest release on PyPI and the `main` branch receive fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/dersders0120-rgb/minecore/security/advisories/new)
instead. Include the MineCore version, your operating system and the steps or
file that trigger the problem.

You will get a first answer within 7 days. Relevant areas include project
package (`.mcproj`) parsing, file importers (CSV, DXF, OMF and similar) and
the Python scripting API.
